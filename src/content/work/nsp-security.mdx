Directed the modernization of a global access control platform from legacy Delphi to .NET 8 microservices, supporting 1,000 properties with zero downtime.

- **Architectural Modernization:** Directed the end-to-end transition from legacy Delphi to .NET 8 microservices.
- **Event-Driven Resilience:** Implemented RabbitMQ to decouple core domain events with robust message schemas.
- **IoT Engineering:** Engineered a fault-tolerant communication layer handling 10,000 concurrent device connections via MQTT.
- **Distributed Integrity:** Enforced strict idempotency across lock-control APIs using request tracking.
