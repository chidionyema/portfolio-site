Worked on the backend of a cash deposit platform handling institutional deposits across multiple banks.

- **Zero-loss messaging** for critical financial events (interest rate changes, deposit instructions) using the Transactional Outbox pattern with Azure Service Bus. A broker outage no longer means lost updates.
- **Contract-driven API governance** ensuring no breaking changes between services. Consumer-driven tests caught incompatibilities before deploy, not after.
- **66% faster deployments** by rebuilding the CI/CD pipeline — what used to be a 45-minute manual process became a 15-minute automated one.
- **Operational visibility** through Prometheus metrics and Grafana dashboards, reducing mean time to resolution for production incidents.
