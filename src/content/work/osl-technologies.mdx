Built the real-time event processing pipeline behind security monitoring for airports and large venues.

- **Millions of events per minute** from cameras, sensors, and access points, ingested through Kafka with strict schema validation to reject malformed data before it enters the pipeline.
- **Sub-second threat alerting** using Elasticsearch percolation queries — incoming events are matched against millions of risk profiles in real time, not in batch.
- **30% reduction in false positives** by integrating ML-driven analytics into the detection pipeline, letting security teams focus on real threats instead of noise.
- **99.99% uptime** via Kubernetes-orchestrated microservices with automated scaling and self-healing. A node failure does not interrupt event processing.
